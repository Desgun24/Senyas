# Senyas 1.0.0

Windows x64 release with the full learning app, bundled lesson videos, and one-click setup.

## Windows setup

Extract the Windows x64 ZIP into a permanent writable folder, then double-click **Install Senyas.cmd**. Setup downloads a private Python runtime and pinned libraries, checks the bundled content and model, creates Desktop and Start menu shortcuts, and opens Senyas. No separate Python, Git, or external dataset installation is needed. The first setup requires internet; lessons and recognition run locally afterward.

## Included

- All 105 words in 10 category levels, with silent bundled demonstration videos.
- Watch, copy with a live camera, replay, and next lesson flow.
- Topic checkbox quizzes, category quizzes, and a 105-word final exam.
- Persistent progress, sidebar navigation, and model settings.
- Decision Tree recognition by default and feature-aware developer explanations.
- Packaging that excludes virtual environments, downloaded dependencies, raw datasets, and personal learner history.

## Limits

This build targets Windows x64 with Edge or Chrome and a working camera. Recognition scores depend on the existing model and recording conditions. Camera preview is live; each short recording is analyzed after capture. Face expression and explicit palm-facing classification are not engineered features in this version.
